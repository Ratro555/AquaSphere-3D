🐠 AquaSphere 3D — Интерактивный Сферический Аквариум на Three.js

Полнофункциональный интерактивный 3D-аквариум, созданный на HTML5, Tailwind CSS и Three.js. Проект не требует сборки, сервера или установки npm-пакетов — все скрипты и текстуры встроены в один единственный самодостаточный HTML-файл.

✨ Основные особенности

🖼️ Реалистичная Сферическая Среда:

Прозрачная стеклянная сфера с преломлением света, дуговыми верхними бликами, мениском воды и донной подсветкой.

🐟 Детализированные 3D-рыбки:

6 уникальных видов (рыба-клоун, желтая зебрасома, рыба-бабочка, неон, розово-золотая и золотая рыбка).

Процедурно сгенерированная текстура чешуи и полупрозрачные плавники.

Живая волнообразная биомеханика плавания с изгибом тела.

🦈 Хищная Акула:

Кнопка запуска акулы, которая патрулирует аквариум и каждые 5 секунд охотится на рыбок (счетчик на кнопке «+ Рыбка» динамически уменьшается).

🌿 Флора и Декорации:

Валуны с зеленым мхом, разноцветные пушистые коралловые кусты, мягкие губчатые рифы и колышущиеся от течения водоросли.

🫧 Интерактивность и Аэрация:

Поток поднимающихся пузырьков воздуха с регулировкой интенсивности («Выкл», «Норма», «Макс»).

Кормление: при нажатии на кнопку сверху падают извивающиеся червячки-мотыль, за которыми рыбки устремляются со всего аквариума.

💡 Режимы Освещения:

Переключение между стилями: «День», «Риф-Неон» и «Золотой Закат».

💾 Скачивание:

Кнопка прямого скачивания готового HTML-файла на устройство.

🚀 Как запустить проект

Скачайте файл 3d_realistic_aquarium.html из репозитория.

Дважды кликните по нему, чтобы открыть в любом современном браузере (Chrome, Firefox, Safari, Edge).

💻 Управление

🖱️ Вращение камеры: Зажмите левую кнопку мыши (или палец на экране) и перетаскивайте курсор.

🔍 Зум: Прокрутите колесико мыши.

✨ Покормить: Двойной клик по поверхности воды или кнопка «🪱 Покормить».

🛠️ Технологический стек

HTML5 / CSS3 / JavaScript (ES6+)

Three.js (WebGL 3D рендеринг)

Tailwind CSS (Интерфейс в стиле Glassmorphism)
